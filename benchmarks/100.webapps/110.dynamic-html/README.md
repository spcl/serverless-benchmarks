# 110.dynamic-html - Dynamic HTML

**Type:** Webapps
**Languages:** Python, Node.js, Java, .NET
**Architecture:** x64, arm64

## Description

The benchmark represents a dynamic generation of webpage contents through a serverless function. It generates an HTML from an existing template, with random numbers inserted to control the output. It uses the `jinja2` library on Python and Mustache templates elsewhere: `mustache` on Node.js, `mustache.java` on Java, and `Stubble` on .NET.
