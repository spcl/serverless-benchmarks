# 311.compression - Compression

**Type:** Utilities
**Languages:** Python, Node.js, .NET
**Architecture:** x64, arm64

## Description

The benchmark implements a common functionality of websites managing file operations - gather a set of files in cloud storage, compress them together, and return a single archive to the user. It implements the .zip file creation with the `shutil` standard library in Python and `System.IO.Compression` in .NET.
